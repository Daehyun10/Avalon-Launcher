# Modpacks and Minecraft versions

AVALON Launcher loads its profile catalog from:

https://raw.githubusercontent.com/Daehyun10/avalon-mods/main/distribution.json

Select the profile name below the launch button to choose a registered modpack and Minecraft version. The selection is saved between launches. Each profile uses its own instance directory for settings and saves. Optional mods are available in Settings > Mods; required mods are always enabled.

Mod JARs, Forge files, and profile metadata live in [avalon-mods](https://github.com/Daehyun10/avalon-mods). See that repository's README for publishing a mod update and generating another Minecraft version. The launcher refreshes the catalog before game launch and validates downloaded files against their hashes.

Only the tested AVALON 1.18.2 / Forge 40.2.0 profile is currently registered. Different Minecraft versions require matching loader files, Java requirements, and compatible builds of every mod. They become available after being added to the catalog; arbitrary versions are not automatically generated by the launcher.

Launcher executable updates continue to use this repository's GitHub Releases. Mod updates use the catalog repository and do not require another launcher release.

## 한국어

시작 문구 아래 프로필 이름을 누르면 등록된 모드팩과 Minecraft 버전을 선택할 수 있습니다. 현재 제공되는 프로필은 AVALON 1.18.2 / Forge 40.2.0입니다. 추가 버전은 avalon-mods 저장소에 호환되는 실행 프로필을 등록하면 나타납니다.

모드를 수정한 후 빌드한 JAR과 배포 목록을 함께 올려야 사용자에게 적용됩니다. 런처는 게임 시작 전 목록을 갱신하고 파일 해시를 검사합니다. 필수 모드는 항상 적용되며 선택 모드는 설정의 Mods 항목에서 변경합니다.
